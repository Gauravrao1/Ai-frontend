# BiasLens AI Frontend

Run with:

```bash
npm install
npm run dev
```

For local development, keep `VITE_API_URL=/api` in `.env` and use the Vite proxy defined in `vite.config.js`.
For Vercel deployment, set `VITE_API_URL=https://ai-backend-fawn-nine.vercel.app` in Project Settings or `vercel.json`.
